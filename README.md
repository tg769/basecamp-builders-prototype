# Gear Rental Prototype

High fidelity prototype for our CS 477 (HCI) project. It is a gear rental site for NAU Outdoor Adventures, made to be used on a phone.

Team: Basecamp Builders (Group 5), Tanmay Ghate, Aryan Sharma and Kalyana Pabbisetty.

## How to run it

Download or clone this repo and open `index.html` in a browser. You don't need to install anything. On a laptop it shows inside a phone frame, on a phone it fills the screen.

## What you can try

The main workflow is holding a tent and cancelling it:

1. Tap the 2-person tent on the home screen.
2. Pick how many you want and a pickup time, then tap "Hold it, free".
3. Read the confirmation, then tap "Cancel hold" and confirm in the popup.

The other workflow is the trip helper:

1. Tap "Plan my trip", answer the questions and tap "Show me gear".
2. Remove anything you don't need, then tap "Hold it, free".
3. If you set the group to 5 or more people it becomes a request that staff confirm, with a status tracker and the desk phone number.

You can also change the trip dates (the counts change with them) and look at the My gear and Help tabs. Refresh the page to start over.

## Notes

It is only the UI, there is no backend. The hours, prices, counts and phone number are made up, same as in our paper prototype tests.

Files: `index.html`, `style.css` and `script.js`.
